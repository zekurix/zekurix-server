# Examples

This directory contains deployment and usage examples for Zekurix Server.

Examples are organized by technology. Each example is self-contained and includes its own documentation.

## Available technologies

| Technology | Description |
| --- | --- |
| compose/ | Docker Compose deployment examples |

> [!NOTE]
> These examples are intended as starting points. Review and adapt their
> configuration, security settings, resource limits, and networking before
> using them in production.
